## 📌 Overview

RoboReviews is an end-to-end NLP pipeline that automatically classifies the sentiment of product reviews. Built across 18 commits of iterative development, it demonstrates the full ML workflow from raw text to a trained classifier.

---

## ✨ Features

- 🔤 **Text Preprocessing** — cleaning, tokenisation, stopword removal, lemmatisation
- 📐 **Feature Engineering** — TF-IDF vectorisation with n-gram support
- 🤖 **Multiple Models** — Logistic Regression, Naive Bayes, and SVM compared
- 📊 **Full Evaluation** — accuracy, F1-score, confusion matrix, ROC curves
- 🔍 **Error Analysis** — inspection of misclassified samples
